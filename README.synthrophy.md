# Synthrophy Office desktop editor (unofficial build)

An offline word processor, spreadsheet and presentation editor for Synthrophy Office by LegitShield, built from the open-source Collabora Office desktop sources.
It is **not** made, endorsed or supported by Collabora Productivity or The Document Foundation.

Our changes are branding only (name, icons and logos, palette, product text, About note, vendor, no automatic updates), produced by `nextcloud/clients/office/brand-office.mjs`
in https://github.com/legit-shield/synthropy-office, applied to the upstream monorepo (https://gerrit.collaboraoffice.com/online). Upstream history is not included in this repository.
No Collabora or LibreOffice name or logo is used for the product name, icons or installer.
